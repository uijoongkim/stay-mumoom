# 네이버·에어비앤비 연동 가이드

## 현재 구현 상태

| 제공자 | 구현 모드 | 데이터 |
|---|---|---|
| 네이버 | NAVER API HUB 공식 지역 검색 | 업체명, 분류, 설명, 주소, 좌표, 홈페이지/검색 링크 |
| 에어비앤비 | 입력한 지역·날짜·인원의 공식 사이트 검색으로 외부 이동 | API 데이터 수집 없음 |

## 네이버 인증 설정

NAVER API HUB 콘솔에서 서비스를 구독하고 Application을 등록해야 Client ID와 Client Secret을 발급받을 수 있습니다.[2]

1. NAVER Cloud Platform 콘솔에 로그인합니다.
2. `Application Services > NAVER API HUB > Application`으로 이동합니다.
3. Application을 등록하고 **NAVER Search > 지역 검색**을 활성화합니다.
4. Client ID와 Client Secret을 확인합니다.
5. 프로젝트 루트에서 다음 명령을 실행합니다.

```bash
cp .env.example .env
```

6. `.env`에 발급받은 값을 입력합니다. 채팅, Git, 스크린샷에 실제 Secret을 넣지 마세요.

```dotenv
NAVER_API_HUB_CLIENT_ID=실제_Client_ID
NAVER_API_HUB_CLIENT_SECRET=실제_Client_Secret
```

7. 기존 서버를 종료하고 실데이터 모드로 실행합니다.

```bash
npm run start:live
```

8. 화면에 지역·체크인·체크아웃·인원을 입력하고 `이 조건으로 네이버 검색`을 누릅니다.

`.env`는 `.gitignore`에 포함되어 있습니다. 브라우저에는 키를 전달하지 않으며 Node 서버가 요청 헤더에만 넣습니다.

## 네이버 데이터 수집 방식

지역 검색의 공식 요청 경로는 `GET /search/v1/local`이며 Client ID와 Client Secret 헤더를 사용합니다. 한 번에 받을 수 있는 결과는 최대 5개이고 검색 시작 위치는 1로 고정되어 있습니다.[1]

무료 PoC 호출량을 제한하기 위해 입력 지역마다 다음 6개 핵심 유형만 사용합니다.

- `{지역} 감성 숙소`, `{지역} 가족 펜션`, `{지역} 한옥스테이`
- `{지역} 풀빌라`, `{지역} 호텔`, `{지역} 숙박`

각 질의를 `sort=comment`로 요청해 리뷰 활동 기반 후보를 먼저 받습니다. 이는 별점 정렬이나 별점 필터가 아닙니다. API가 별점을 반환하지 않기 때문에 별점이 높은 숙소라고 표시하지 않습니다. 최대 원본 응답은 30건이며 입력 지역의 주소와 숙박 관련 업종을 확인한 뒤 이름·좌표 기준으로 중복을 제거합니다. 지역별 배치는 3개씩, 서로 다른 지역을 포함한 프로세스 전체 NAVER fetch도 동시에 3개까지만 수행합니다. 지역별 결과는 10분간 서버 메모리에 캐시하며 같은 지역의 동시 캐시 미스는 하나의 요청으로 합칩니다. 공개 `refresh` 우회는 없고 `/api/listings`는 IP별 10회/분으로 제한합니다.

공식 지역 검색 응답에는 업체명, 홈페이지 링크, 분류, 설명, 지번/도로명 주소와 WGS84 좌표가 포함됩니다.[1] 가격, 날짜별 재고, 수용 인원, 욕실, 침실, 편의시설, 평점 및 숙소 사진은 이 API의 응답 필드가 아닙니다. 서비스는 이를 추정하거나 임의로 채우지 않고 `원문 확인`으로 표시합니다.

## 에어비앤비 제한과 현재 설계

에어비앤비 API는 일반 사용자 로그인만으로 숙소 검색 권한을 주는 공개 API가 아닙니다. API 프로그램 참여에는 관련 프로그램 요건, 파트너 약정과 데이터 보안 평가 등이 요구됩니다.[3]

에어비앤비 API 약관은 허용된 프로그램 범위를 벗어난 정적 사본/데이터베이스 구축, 가격 등의 분석·추출, 문서화되지 않은 API 사용, 경쟁·유사 서비스에서의 API 사용, 금지 페이지 크롤링과 접근 제한 우회를 제한합니다.[3] 따라서 현재 구현은 다음만 제공합니다.

- 사용자가 입력한 지역·체크인·체크아웃·숙박 인원을 에어비앤비 공식 검색 페이지에 전달해 새 탭으로 열기
- 에어비앤비 콘텐츠, 가격, 후기, 사진을 저장하거나 프록시하지 않기
- 에어비앤비 세션 쿠키나 비밀번호를 받지 않기

향후 에어비앤비의 서면 파트너 승인과 해당 서비스 용도에 맞는 API Scope를 받으면 `createNaverProvider`와 같은 별도 어댑터로 추가할 수 있습니다. 승인 전에는 비공개 API나 브라우저 세션을 이용한 우회 수집을 구현하지 않습니다.

## 사진 정책

네이버 지역 검색 API는 숙소 사진을 제공하지 않고, 에어비앤비 사진은 승인된 API 콘텐츠 사용 권한 없이 캡처·복제·핫링크하지 않습니다. 샘플 카드는 자체 제작 일러스트를 쓰지만 NAVER 실데이터 카드는 `사진 미제공 · 공식 원문에서 확인` 상태를 표시합니다. 실제 사진은 다음 중 하나가 확보될 때만 연결합니다.

1. 숙소 운영자가 직접 제공하고 사용을 허가한 사진
2. 제휴 API가 표시·캐시 조건과 함께 제공한 이미지 URL
3. 라이선스와 출처가 확인된 공개 이미지

## 오류 처리

| 상태 | 의미 | 조치 |
|---|---|---|
| `NAVER_NOT_CONFIGURED` / 503 | 환경변수 없음 | `.env` 설정 후 `npm run start:live` 재실행 |
| 401/403 | 키 오류 또는 API 미활성화 | Application의 인증 정보와 지역 검색 권한 확인 |
| 429 | 호출 한도 초과 | 캐시를 사용하고 다음 할당 주기에 재시도 |
| 일부 검색 실패 | 6개 중 일부 요청 실패 | 성공 결과는 표시하고 상태 문구에 부분 실패 표기 |
| 전체 검색 실패 | 6개 질의 모두 실패 | 빈 성공 결과를 캐시하지 않고 502 오류로 표시한 뒤 재시도 |

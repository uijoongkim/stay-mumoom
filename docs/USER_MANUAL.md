# 머무름 PoC 사용자 매뉴얼

## 1. 시작하기

터미널에서 아래 명령을 실행합니다.

```bash
cd /Users/kimuijoong/Desktop/JJOONGS/AI/agent/develop/stay-mumoom
npm start
```

브라우저에서 `http://127.0.0.1:4173`으로 접속합니다. 메인 화면에서 `둘만의 여행` 또는 `가족 여행`을 선택하면 목적이 적용된 탐색 화면으로 이동합니다. 종료할 때는 실행 중인 터미널에서 `Control + C`를 누릅니다.

### 네이버 실데이터 연결

NAVER API HUB에서 Application과 지역 검색 권한을 등록한 뒤 프로젝트의 `.env.example`을 `.env`로 복사하고 Client ID/Secret을 입력합니다. 상세 절차는 `PROVIDER_INTEGRATION.md`를 확인하세요.

```bash
npm run start:live
```

탐색 화면의 `네이버 추천 후보 불러오기`를 누르면 공주 관련 핵심 검색 6회의 결과를 합치고 중복을 제거해 최대 30곳을 표시합니다. `sort=comment`는 리뷰 활동 기반 후보 정렬이며 별점 필터가 아닙니다. 키가 설정되지 않았으면 상태 영역에 `네이버 API 인증 설정이 필요합니다`가 나타납니다.

`에어비앤비 공주 검색`은 에어비앤비 공식 사이트를 새 탭으로 엽니다. 파트너 승인 전에는 에어비앤비 로그인이나 숙소 데이터 수집을 수행하지 않습니다.

## 2. 숙소 찾기

### 화면 구성

- `/`: 여행 목적 선택과 서비스 원칙을 보여주는 메인 화면
- `/explore.html`: 목적·예산·인원·욕실·편의시설로 후보를 비교하는 탐색 화면
- `/connections.html`: 향후 통합 로그인과 공급자 연결 상태를 보여주는 준비 화면

현재 로그인 버튼은 의도적으로 비활성화되어 있습니다. 플랫폼 비밀번호를 받지 않으며 향후 각 공급자가 승인한 OAuth/OIDC만 연결합니다.

### 여행 목적 선택

화면의 첫 단계에서 다음 중 하나를 선택합니다.

- **둘만의 쉼**: 감성, 자연, 프라이빗 태그와 욕조·편백·사우나를 우선합니다.
- **가족 여행**: 가족/자연 태그, 넉넉한 정원, 수영장·바비큐·주방을 우선합니다.
- **친구들과**: 그룹/액티비티 태그, 넉넉한 정원, 바비큐·수영장·사우나를 우선합니다.

선택 즉시 추천 점수와 결과 순서가 바뀝니다.

### 필수 조건 입력

- **어디로 떠날까요?**: `평창`, `제주`, `한옥`처럼 지역, 숙소명 또는 테마를 입력합니다.
- **1박 최대 금액**: 슬라이더로 9만~30만원 범위를 지정합니다.
- **최소 욕실 수**: 1개 또는 2개 이상을 선택합니다.
- **숙박 인원**: 2, 4, 6, 8명 이상을 선택합니다.
- **편의시설**: 여러 항목을 선택하면 선택 항목을 **모두** 갖춘 숙소만 나타납니다.

조건은 입력 즉시 적용됩니다. 결과가 없다면 빈 결과 화면의 `전체 조건 초기화`를 누릅니다.

## 3. 결과 비교하기

각 카드에는 다음 정보가 같은 순서로 표시됩니다.

- 데이터 출처
- 목적별 매칭 점수와 추천 이유
- 지역과 서울/현재 위치 기준 예상 거리
- 최대 인원, 욕실, 침실
- 핵심 편의시설
- 비교용 1박 가격

오른쪽 상단 정렬 메뉴에서 `추천순`, `낮은 가격순`, `가까운 거리순`을 선택할 수 있습니다.

## 4. 현재 위치 사용하기

결과 위의 `서울 기준` 버튼을 누르면 브라우저가 위치 권한을 요청합니다.

- 허용: 현재 좌표를 브라우저 메모리에서 사용해 거리를 다시 계산합니다.
- 거부/오류: 서울 기준을 유지합니다.

PoC는 위치를 서버에 전송하거나 저장하지 않습니다. 페이지를 새로 열면 서울 기준으로 돌아갑니다.

## 5. 찜과 상세 정보

- 카드 이미지 오른쪽 위 하트 버튼을 누르면 찜합니다.
- 상단 `찜` 버튼을 누르면 현재 조건에 맞는 찜 목록만 봅니다.
- 찜 정보는 현재 브라우저의 localStorage에 저장됩니다.
- `자세히 보기`를 누르면 이용 가능한 정보와 API 수집 시각을 확인합니다.
- 샘플 카드는 `example.com`, 네이버 실데이터 카드는 업체 홈페이지 또는 네이버 검색을 새 탭으로 엽니다.
- 네이버 카드의 `가격 정보 없음`, `원문 확인`은 오류가 아니라 지역 검색 API에 해당 필드가 없다는 의미입니다.

## 6. 주의사항

샘플 카드의 숙소, 가격과 후기는 기능 검증용입니다. 네이버 실데이터의 업체명·주소·좌표는 공식 지역 검색 응답이지만 숙박 가능 여부를 보장하지 않습니다. 예약 가능 여부, 세금·수수료 포함 최종 가격, 인원, 욕실, 편의시설, 사진과 취소 정책은 원문에서 다시 확인해야 합니다.

## 7. 문제 해결

| 증상 | 해결 방법 |
|---|---|
| 페이지가 열리지 않음 | `npm start` 터미널이 실행 중인지 확인합니다. |
| 4173 포트가 사용 중 | `PORT=5000 npm start` 후 `http://127.0.0.1:5000`으로 접속합니다. |
| 결과가 없음 | 조건 초기화 후 조건을 하나씩 적용합니다. |
| 위치가 바뀌지 않음 | 브라우저 사이트 설정에서 위치 권한을 확인합니다. |
| 찜을 지우고 싶음 | 각 카드의 하트를 다시 누르거나 브라우저 사이트 데이터를 삭제합니다. |
| 네이버 API 인증 설정 필요 | `.env`의 두 키를 확인하고 `npm run start:live`로 서버를 재실행합니다. |
| 네이버 결과가 30개 미만 | 공식 API가 검색어당 최대 5개만 제공하며 중복 제거 후 실제 고유 업체 수가 상한보다 적을 수 있습니다. |
